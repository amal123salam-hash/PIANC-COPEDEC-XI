# PWA Icons

Place your app icons here. Required files:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png
- screenshot-mobile.png  (390x844, optional but recommended for Play Store)

## Generate icons quickly

1. Go to https://realfavicongenerator.net
2. Upload your logo (at least 512x512 px)
3. Download the package and place the PNGs here

Or use PWA Builder's image generator:
https://www.pwabuilder.com/imageGenerator
